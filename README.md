# IOU Adjustment System

Web app for AKSID employee IOU (expense) submission and approval tracking.

- `index.html` — Dashboard (Home, Submit, Track, Approve, Notify)
- `submit.html` — Standalone submission form

Data syncs to SharePoint (`IOUTracker` list) via a Make.com webhook, with browser `localStorage` as an offline fallback.

Live at: https://iou.aksidcorp.com
